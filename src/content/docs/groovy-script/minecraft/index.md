You can use GroovyScript to modify a number of vanilla recipes and values.

* GroovyScript uses [IIngredients](/groovy-script/minecraft/iingredient/) to refer to an item, fluid, ore dictionary, other `IIngredient`s, or a list of the above.

* See how to access [Items](/groovy-script/minecraft/iingredient/item/) for use in other compat, and modify their publicly available values.

* Learn what a [Resource Location](/groovy-script/minecraft/resource_location/) is, and how Minecraft uses it.

* Edit vanilla crafting recipes via [Crafting](/groovy-script/minecraft/helpers/crafting/). Includes a fully featured Recipe Builder to make
  editing recipes faster.

* Edit smelting recipes via [Furnace](/groovy-script/minecraft/helpers/furnace/).

* Edit the Ore Dictionary via [Ore Dictionary](/groovy-script/minecraft/helpers/ore_dict/).

* Edit loottables via the [Loot](/groovy-script/minecraft/loot/) compat.

* Add custom tooltips to items via the [Tooltip](/groovy-script/minecraft/tooltip/) compat.

* Listen to and cancel events via the [Event](/groovy-script/minecraft/events/) compat.
