You can use GroovyScript to modify a number of vanilla recipes and values.

* GroovyScript uses [IIngredients](/zh/groovy-script/minecraft/ingredient/) to refer to an item, fluid, ore dictionary, other Ingredients, or list of any of the above.

* See how to access [Items](/zh/groovy-script/minecraft/item/) for use in other compat, and modify their publicly available values.

* Learn what a [Resource Location](/zh/groovy-script/minecraft/resource_location/) is, and how Minecraft uses it.

* Edit vanilla crafting recipes via [Crafting](/zh/groovy-script/minecraft/crafting/). Includes a fully featured Recipe Builder to make
  editing recipes faster.

* Edit smelting recipes via [Furnace](/zh/groovy-script/minecraft/furnace/).

* Edit the Ore Dictionary via [Ore Dictionary](/zh/groovy-script/minecraft/ore_dictionary/).

* Edit loottables via the [Loot](/zh/groovy-script/minecraft/loot/) compat.

* Add custom tooltips to items via the [Tooltip](/zh/groovy-script/minecraft/tooltip/) compat.

* Listen to and cancel events via the [Event](/zh/groovy-script/minecraft/events/) compat.
